# 🚀 Overview

**HireTrack** is an **AI-powered Job Application Management Platform** built using the **MERN Stack**. It enables job seekers to organize, monitor, and optimize their entire job search journey—from discovering opportunities and parsing resumes to tracking interview progress and comparing offers.

The platform centralizes every stage of the recruitment process in a clean, intuitive dashboard while leveraging **Google Gemini AI** for intelligent automation and productivity.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/HireTrack.git
```

---

## Navigate

```bash
cd HireTrack
```

---

## Backend

```bash
cd hiretrack-project/hiretrack-backend

npm install

npm run dev
```

---

## Frontend

```bash
cd hiretrack-project/hiretrack-frontend

npm install

npm run dev
```

---

Open your browser

```
http://localhost:5173
```
